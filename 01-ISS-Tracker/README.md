# 🛰️ ISS Tracker

A Python project that tracks the current location of the International Space Station (ISS) using an API.

## 🚀 Features

- Gets the current ISS latitude
- Gets the current ISS longitude
- Displays the latest ISS location
- Uses a public API
- Built with Python

## 🛠️ Technologies

- Python
- Requests
- REST API
